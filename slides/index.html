Slide 06 / 15

Nhóm Endpoints Nghiệp Vụ Chính:

AUTH POST /api/auth/login & /register (JWT)

RBAC GET|PUT /api/admin/users & /stats

DEL /api/transactions/:id (Xóa & hoàn ví)

GET /api/budgets/progress (Tiến độ tháng)

GET /api/analytics/category-breakdown

Các Middleware Tiêu Chuẩn:

1. Auth & RBAC (authMiddleware.js):

Xác thực Bearer JWT token, giải mã payload và phân quyền Admin/User ngăn chặn truy cập trái phép.

2. Logger & Validator (logger.js / validator.js):

Ghi log request ms; kiểm tra số tiền > 0, tránh injection dữ liệu.

3. Centralized Error Handler (errorHandler.js):

Bắt toàn bộ lỗi runtime, trả về cấu trúc lỗi chuẩn JSON { success: false, error: { message, code } }.

Tất cả API đều tuân thủ chuẩn RESTful, trả về mã trạng thái HTTP chuẩn (200 OK, 201 Created, 400 Bad Request, 404 Not Found).

06. Cơ Chế Bất Biến Tài Chính (Financial Invariants)

Slide 07 / 15
Bảo Toàn Số Dư Ví (Conservation)

Số dư hiện tại của từng ví luôn bằng:

CurrentBalance = InitialBalance + ∑Income - ∑Expense

Đảm bảo không bao giờ có sự chênh lệch giữa tổng số dư hiển thị và lịch sử giao dịch.

Đồng Bộ Giao Dịch Nguyên Tử

Mọi thao tác sửa hoặc xóa giao dịch đều tự động:

  • Hoàn tác số tiền cũ vào ví gốc.
  • Trừ/cộng số tiền mới vào ví đích.
  • Cập nhật lại ngân sách danh mục.

Được bảo vệ bằng SQLite Transaction nội bộ.

An Toàn Toán Học (Zero-Division)

Tỷ lệ tiết kiệm và tỷ trọng chi tiêu:

if (income === 0) return 0;

SavingsRate = (Income - Expense) / Income * 100;

Tránh hoàn toàn lỗi NaN hoặc Infinity khi hệ thống mới khởi tạo chưa có giao dịch thu.

✅ Đã được kiểm tra qua 15/15 ca kiểm thử tính bất biến (Invariant Tests) đạt kết quả tuyệt đối.
