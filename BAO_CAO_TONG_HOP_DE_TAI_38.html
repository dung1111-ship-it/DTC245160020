🎤 Các Câu Hỏi Vấn Đáp Phổ Biến (Kèm Câu Trả Lời Điểm A+)

1. Tại sao em sử dụng Nginx đứng trước Backend Node.js?

→ Nginx đóng vai trò Reverse Proxy: Định tuyến tập trung cổng 80, giải phóng tải tĩnh cho Node.js, bật Gzip nén dữ liệu, bảo mật bằng Security Headers (OWASP) và Rate Limiting 15 request/giây để chống tấn công Brute-force/DDoS.

2. Hệ thống thu thập metrics và giám sát như thế nào?

→ Em tích hợp thư viện prom-client xuất ra endpoint /metrics. Prometheus cào định kỳ 5s lưu vào Time-Series DB, sau đó Grafana kết nối vào Prometheus để hiển thị Dashboard trực quan (RPS, Latency 95th percentile, Memory Heap).

3. Em đã thực hiện Hardening (Gia cố bảo mật) những gì?

→ Em gia cố 3 lớp: (1) Nginx chặn iframe Clickjacking, ẩn phiên bản máy chủ; (2) Dockerfile chuyển quyền sang USER node non-root; (3) CSDL PostgreSQL chạy trong mạng ảo cách ly expense_net, cấu hình phân quyền và tường lửa UFW.
